interface IFormater
{
    {abstract} std::string Format(const std::array<VariableType, 4>& data)
}

class Formater
{
    + Format(data): std::string
}

IFormater <|.. Formater

note bottom of IFormater
  Интерфейс для форматирования данных в строку
end note

note bottom of Formater
  Форматирует 4 величины в строку по ТЗ:
  "Давление: XXX.XX гПа Влажность: XXX.XX %
   Температура: XXX.XX C Точка росы: XXX.XX C\r\n"
end note
